# Security Policy

## Supported Versions

Security updates are provided for these versions:

| Version | Supported                 |
| ------- | ------------------------- |
| 4.0.x   | :white_check_mark:        |
| 3.x     | :white_check_mark: (bug fixes only) |
| < 3.0   | :x:                       |
